# 🌐 PersonalPortfolio

**PersonalPortfolio** is the signature developer portfolio and personal brand platform for **McLein Jei Onza** (Computer Science student and software developer). Engineered with semantic HTML5, modern CSS3 custom properties (design tokens, Bento Grid, 3D transforms), and Vanilla ES6+ JavaScript, it showcases software engineering projects, technical skillsets, academic milestones at Cagayan State University, DTI YEP entrepreneurship/pitch awards, and contact channels. It features an interactive **3D coverflow project carousel**, an interactive **developer terminal** emulator, system-synchronized **dark/light theme switching**, an asynchronous AJAX contact form, and live visit/like metrics powered by Vercel Serverless Functions and Abacus API.
