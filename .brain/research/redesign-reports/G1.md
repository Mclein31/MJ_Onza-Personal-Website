# G1 Report — About & Journey Fixes

## Summary of Changes

### 1. About Heading Highlight Box Overlap (`css/about.css`)
- **Root cause**: `.about__intro h2` inherited `line-height: 0.95` from `css/base.css`, while Geist at `font-weight: 900` has an inline content-box height of `1.30em`. Because `.hl` paints across its full inline box height, `how data flows.` overlapped the line above (`now learning`, and `always,` on phones) by `14px`–`28px` across `375px`–`1920px` widths (and overlapped itself when wrapping across two lines at `1920px`).
- **Fix**:
  - Set `line-height: 1.32;` on `.about__intro h2` in `css/about.css`.
  - Set `-webkit-box-decoration-break: clone; box-decoration-break: clone; padding: 0 0.12em;` on `.about__intro .hl` while keeping the signal-red wipe background and `--color-signal-ink` text.
- **Verified**: Zero cross-line or self-line highlight overlaps measured across `375`, `393`, `440`, `466`, `626`, `768`, `860`, `960`, `1280`, `1440`, and `1920`px wide.

### 2. Mobile "What I do" Gap (`css/about.css`)
- **Root cause**: Between `.about__intro` and `.does`, `<i data-signal-anchor data-signal-side="left">` had `height: 1px; margin-top: var(--space-xl)` (`40px`), and `@media (max-width: 860px)` gave `.about .does` `margin-top: var(--space-2xl)` (`64px`), producing `40 + 1 + 64 = 105px`.
- **Fix**: Inside `@media (max-width: 860px)` in `css/about.css`, kept `[data-signal-anchor]` in-flow for `js/signal.js` (`offsetParent !== null`) with `position: relative; top: 16px; height: 0; margin-top: 0;` and set `.about .does { margin-top: 32px; }`.
- **Verified**: `.does` top minus `.about__intro` bottom measures `32px` at `375`, `393`, `440`, `466`, `626`, `768`, and `860`px.

### 3. `#about` Scroll Margin (`css/about.css`)
- **Root cause**: `.section[id]` in `css/base.css` used `scroll-margin-top: calc(var(--space-lg) - var(--pad-top))` (`-120px` on desktop), which plus `.about__eyebrow` left `#about h2` landing `86.16px` below `.nav__inner` (exceeding the `< 80px` nav-jump check).
- **Fix**: Added `scroll-margin-top: calc(-1 * var(--pad-top));` to `.about.band--night` in `css/about.css`.
- **Verified**: Clicking `.nav__links a[href="#about"]` lands `#about h2` `62.16px` below `.nav__inner` (`20.7px` clearance above `02 / ABOUT`).

### 4. Journey Image Dimensions & Highlight Boxes (`index.html`, `css/journey.css`)
- **Image dimensions (`index.html`, `#journey` only)**: Added explicit `width` and `height` attributes matching the WebP assets to the four content `<img>` elements that lacked them:
  - `assets/images/trainings/dti-yep-pitch-medcore.webp` → `width="1800" height="1012"`
  - `assets/images/projects/mulat-1-1600.webp` → `width="1600" height="900"`
  - `assets/images/awards/cih-2026-check.webp` → `width="1600" height="900"`
  - `assets/images/projects/advancare-1-1600.webp` → `width="1600" height="900"`
- **Journey highlight boxes (`css/journey.css`)**: Updated `.yr__line` from `line-height: 1.12` to `line-height: 1.32` and `.yr__line span` padding from `0 0.14em 0.04em` to `0 0.14em` so the inverted highlight box no longer overlaps `.yr__place` above it (previously `0.6px`–`1.5px`) or wrapped lines.
- **Short desktop Journey media cap (`css/journey.css`)**: Adjusted `@media (min-width: 861px)` `.yr__media` max-height offset from `252px` to `284px` (and `--workspace` from `312px` to `332px`) so all 7 Journey slides fit at least `16px` above `.years__foot` on `1366×650` screens.
