# W3 — Selected work

## What changed
- **Heading**: `01 / WORK` mono label, "Things I’ve *built.*" (Geist 900, `em.serif` accent in `--color-signal-text`), mono counter pill `NN / 05` moved from the progress foot into the heading row (pinned layout only; still `data-work-count`, `aria-hidden`).
- **Per project**: giant red `.numeral.project__num` (01–05) behind the gallery track (the transparent MockUPhone slides sit over it); `.label.project__fig` `FIG. 0n / NAME`; title Geist 900 at `-0.055em`; tech tags as mono outline chips; the promo button is an ink pill with a red play chip. The current card's numeral is full red and the others sit at 55% (`.is-current`, set in `js/work.js`).
- **Gallery controls**: round ink buttons (44px), red on hover/press; the active dot is a red bar. Panel background removed so the cream shows through.
- **Foot**: progress bar fill is red. "More on GitHub" card keeps ink with a red bottom edge.
- **Dialogs**: video window and screenshot viewer got ink round buttons, a mono red counter, Geist 900 titles. The viewer's base rules live in `css/recognition.css` (W5, loads later), so the overrides in `work.css` use two-class selectors (`.lightbox .lightbox__nav` etc.).
- **Signal anchors**: two `<i data-signal-anchor>` inside `#work`, one before `.work__pin` (`left`) and one after it (`right`); none inside the pinned stage.
- **Compact landscape** (600–759px tall, e.g. 890×626): chips, paragraph, promo button and media padding tightened so the gallery gets 186px instead of 128px. The card width formula (`min(56vw, 640px)` there; `min(74vw, 1180px, …)` otherwise) is untouched.

## Preserved
Pin media query `(min-width: 861px) and (min-height: 600px) and (orientation: landscape)`, stacked layout elsewhere, card sizing formula, gallery masks, transparent slides, promo videos, lightbox and video window behaviour, all `data-*` hooks.

## Files
`css/work.css`, `js/work.js` (one line: `is-current` toggle), `index.html` (work section only). `js/gallery.js`, `js/lightbox.js`, `js/video.js` unchanged (no change needed).

- Not run: 375×667, 466×678, 626×890, 1032×1376, 1920×1080, 2560×1440, dark theme, the video window, and Safari/WebKit. Worth covering in W7's matrix.
- Numerals on stacked phones sit partly under the floating nav while scrolling (decorative, `aria-hidden`).
- My first local server (`python3 -m http.server`) dropped connections and is now blocked; I used `node tests/serve.mjs`.
- Fallbacks: work.css defines `--w-red`/`--w-serif` with fallbacks to the shared tokens, and restyles `.label`, `em.serif`, `.numeral` locally (scoped to `.work`) so it does not depend on load order.
