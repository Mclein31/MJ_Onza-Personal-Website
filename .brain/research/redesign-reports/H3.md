## Verification

- First run (default output dir): 47 passed, 5 failed. All five were `dark layout fits` cases at 320x568, 375x812, 393x852, 430x932 and 600x960. Each failed with `browserContext.close: ENOENT` on a trace file under `test-results/.playwright-artifacts-*`, not with a layout assertion. Another agent running Playwright at the same time most likely cleared the shared `test-results/` directory. The light-mode runs at the same sizes passed.
- Re-run with a private `--output` directory so nothing could collide: **52 passed, 0 failed**.

No test was edited, skipped or loosened.

## Note for other agents
Run these specs with `--output=<scratch dir>` when other agents are also running Playwright. Otherwise the shared `test-results/` directory causes false ENOENT trace failures.
