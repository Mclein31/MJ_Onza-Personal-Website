# Redesign Report — W5 (Activity, Stack, Recognition, Training)

## What Changed

### 1. Activity (`#activity` — `css/activity.css`, `js/activity.js`, `index.html`)
- Restyled the section head with `.label` (`04 / ACTIVITY · GITHUB`), `<em class="serif">` accent (`one square at a time.`), and added `<i data-signal-anchor data-signal-side="left" aria-hidden="true"></i>`.
- Recoloured the 5-step GitHub contribution calendar from `--color-paper-3` (`--lv0`) through 24%, 48%, and 74% `color-mix` intermediates to `--color-signal` (`--lv4`), with crisp square cells (`border-radius: 2px`), flat `--color-paper-hi` surface, 1px `--color-rule` border, and sticky corner masking for horizontally scrolling month labels.
- Upgraded `.activity__stats` to native `<button class="stat" type="button" data-hl="..." aria-pressed="false">` cards inside `<div class="activity__stats">` (resolving `<dl>`/`role="button"` ARIA violations), with Geist 900 totals (`clamp(2.125rem, 3.8vw + 0.5rem, 4rem)`), `.label` titles, mono sub-captions, active red dot/border indicators, and full keyboard/click/hover calendar highlighting.

### 2. Stack (`#stack` — `css/stack.css`, `index.html`)
- Restyled the section head with `.label` (`05 / STACK`), `<em class="serif">` accent (`one schema.`), and added `<i data-signal-anchor data-signal-side="right" aria-hidden="true"></i>`.
- Unified all five schema tables (`python_scripting`, `sql_databases`, `web_fullstack`, `ai_workflows`, `toolchain`) on flat `--color-paper-hi` cards with a `--color-night` ink header bar, `--color-night-ink` cream mono table names, an authored SVG key glyph (`.table__key`) and `PK` badge in `--color-signal`.
- Styled all rows in Geist Mono (`--font-data`, tabular numerals) with `44px` minimum height and red join highlighting (`.row.is-source` in `--color-signal` with `--color-signal-ink` text; `.row.is-joined` in 15% signal tint with a 3px signal inset bar and `--color-signal-text` accents).

### 3. Recognition & Training File Drawer (`#recognition`, `#training` — `css/drawer.css`, `js/drawer.js`, `css/recognition.css`, `index.html`)
- Added `.label` index captions (`06 / RECOGNITION`, `07 / TRAINING`), `<em class="serif">` accents, and signal anchors (`left` in `#recognition`, `right` in `#training`).
- Built an accessible physical file drawer (`.drawer`) used in both `#recognition` (5 award files) and `#training` (8 DTI YEP frames):
  - Upper `.drawer__stage` stacks all `.folder__card` panels in a single CSS Grid cell (`grid-area: 1 / 1`) with `visibility: hidden` on inactive panels, eliminating vertical layout jump when switching folders while keeping the lead award open on load.
  - Lead award (`2nd place, Cagayan Innovation Hack 2026`) is styled as a Signal Red folder (`data-tone="red"`, `--color-signal` fill, `--color-signal-ink` text); remaining folders alternate `cream`, `ink`, `sand`, and `stone` tokens, with the lead tab spanning 2 columns on desktop and full width on narrow viewports so the 5-tab tray has zero orphan gaps.
  - Lower `.drawer__tray` houses standing `<button class="folder__tab" aria-expanded="..." aria-controls="...">` controls with protruding tab ears and a `.drawer__front` handle/label plate (`DRAWER 01 · RECOGNITION (05)` and `DRAWER 02 · TRAINING (08)`).
  - Hover (`pointerType === 'mouse'`, gated by `@media (hover: hover) and (pointer: fine)`), keyboard focus (`focusin`), and tap/click lift the folder tab and reveal the folder's photo and caption; bottom hit-area extension (`::after`) prevents hover jitter.
  - `Enter` and `Space` (plus click/tap) toggle `aria-expanded` (`true`/`false`); arrow keys move focus between tabs.
  - `@media (prefers-reduced-motion: reduce)` removes all lift transforms (`transform: none !important`) and uses opacity-only transitions.
- Preserved `.award__img` + `data-lb="..."` hooks and `.strip` (`[data-strip]`) in `#recognition` so certificates open in the existing photo lightbox (`js/lightbox.js`), and wired `#training` folder photos (`[data-training-lb]`) to `openViewer` from `js/lightbox.js`. Preserved `.lightbox*` rules in `css/recognition.css`.
- Added explicit `width` and `height` attributes on all 5 award `<img>` and 8 training `<img>` tags.
