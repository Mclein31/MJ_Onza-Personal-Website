# F1: no thin fonts (owner feedback)

Instrument Serif Italic removed from the whole site except the hero files (css/hero.css, js/hero.js untouched).

## Changes
- `css/fonts.css`: both Instrument Serif `@font-face` blocks deleted. `assets/fonts/instrument-serif-italic-v5-latin{,-ext}.woff2` deleted. Preload line removed from `index.html`.
- `css/tokens.css`: `--font-serif` now `var(--font-display)` (safety net, no serif ships).
- `css/base.css`: `em.serif` is upright, inherits family, weight and tracking from the heading, coloured `--color-signal-text`. `.label` is Geist Mono 500 at 13px (12px at <=40rem). The night band did not re-map `--color-signal-text` (only `--color-accent-text`), so I added it: `#FF6A5E` in `.band--night`, signal-ink in `.band--signal`. Without it the accent word read dim red on black (contact title).
- `css/work.css`, `about.css`, `journey.css`, `contact.css`: every italic/serif rule cleared (the `.serif` overrides, `--w-serif`, Journey place names, `.yr__note h3`, contact/message em). Journey place names are Geist 500; note titles Geist 700 (also `.keyword`, was 400). `.work .label` raised to 13px/500.
- Bug, Journey title clipped at 1280-1440: `.yr__words > p` was `nowrap`; the highlight line now uses `white-space: normal; text-wrap: balance` (`.yr__line`, all slides), so it wraps instead of clipping. Measured: every highlight box ends inside its column at 390, 1280 and 1440 (single line each).
- Bug, stats pill invisible over night bands: added a 1px hairline ring (`paper` 38% mixed into `ink`) to `.stats` box-shadow in `css/fx.css`.
