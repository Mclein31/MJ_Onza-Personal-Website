# W1 — Foundation

Implements brief sections 3, 4, 6 (Nav, Preloader) and 10. Nothing committed or pushed.

## What changed

**`css/tokens.css`** — all colour, type and motion values rewritten to the brief, both themes, token names kept.
- Light and dark palettes exactly as listed (cream/ink/signal; `--color-night*`, `--color-signal*`).
- `--color-accent`, `--color-accent-2` → `var(--color-signal)`; `--color-accent-text`, `--color-focus` → `var(--color-signal-text)`; `--color-accent-ink` → `--color-signal-ink`; `--color-guide` → signal.
- Dark theme `--color-highlight` is cream with ink text (brief only specified light; mirrors "ink highlight boxes").
- Type: `--font-serif`, `--display-weight: 900`, `--tracking-display: -0.055em`, `--text-giant`. Retuned `--text-hero` (3.5rem–8.5rem), `--text-mega` (4rem–11rem), `--text-section` (2.5rem–5rem). `--head-weight` 650 → 700 (h3/h4 are 650).
- Motion: `--ease-snap` added; all existing easing/duration tokens kept.
- Shadows are now small, neutral drop shadows for floating things only (nav, stats pill, toast). `--grain` is a transparent no-op so `.proof` and other old references resolve.

**`css/fonts.css`** + `assets/fonts/instrument-serif-italic-v5-latin.woff2` (15.7 KB) and `...-latin-ext.woff2` (8.4 KB) — Instrument Serif Italic 400, self-hosted (OFL), `font-display: swap`, same unicode-range split as Geist. Source: Google Fonts v5 files, downloaded once; no runtime request.

**`index.html`** (my regions only): a second `<link rel="preload">` for the latin Instrument Serif file; the nav "Send a message" button is now `<button class="btn-pill nav__hire" … data-message-open>Let’s talk <span class="btn-pill__chip" aria-hidden="true"></span></button>`. `data-message-open` and `.nav__hire` are unchanged hooks.

**`css/base.css`** — new shared components:
- `.label` (Geist Mono 12px, uppercase, .08em, muted; 11px on phones).
- `em.serif` (Instrument Serif italic 400, tracking 0, 1.06em).
- `.numeral` (Geist 900, `--text-giant`, red, `line-height: .8`, non-selectable, no pointer events).
- `.band--night`, `.band--signal`, `.band--paper`: re-map paper/ink/muted/rule/highlight **and the derived tokens** (`--color-card*`, `--color-hover`, `--color-dot`, `--color-mark`, `--color-accent-text`, `--color-focus`, error/success), because a `var()` resolves where it is declared. Each band also sets its own `background` and `color`. `.band--night` uses a brighter red for text (`#FF6A5E`, 6.9:1) since `#C41D10` fails on black; on red, ink stays black and accents become ink; `.band--night` gets 1px `#151515` inset edges in the dark theme so it stays distinct from the page. `.band--paper` is the theme's own paper scheme for a block nested in a night/signal band.
- `.btn-pill` + `.btn-pill__chip` (+ `.btn-pill--lg`): ink pill, ≥48px, red 36px chip, chip rotates 45° on hover/focus (hover-gated). An **empty** chip draws its own ↗ with a CSS mask (Geist has no ↗ glyph); a chip containing an `<svg>` uses that. The pill inverts automatically inside bands; on `.band--signal` the text is cream (`--pill-fg`).
- Global: `h1, h2` use display weight/tracking (`line-height .95`); `::selection` red; `.keyword` is now a red underline; `.hl` unchanged in mechanism (`--wipe`); `.btn--accent` uses signal fill; `.proof` loses the grain layer.

**`css/texture.css`** — paper fibres, liquid glass, marker texture, photo-mount shadows and tilts, and `body`/`.hero` background images are removed. What remains is zero-specificity (`:where`) fallbacks so a section's own CSS always wins: flat `--color-card` for the old glass cards, flat ink for the old inverted panels, a hairline on photos, and the pinned-stage paper (`.work__sticky`, `.years__sticky`). Sections can drop their line when they no longer need it. The `assets/textures/*` files are now unreferenced (left in place; the orchestrator can delete them).

**`css/reveal.css`** — snappier: rise is 600ms opacity / 800ms `--ease-snap`, 32px travel, 60ms stagger; line mask is 1s snap. `.ln` gets 0.14em inline padding (cancelled by negative margin) so italic serif overhangs aren't clipped. `data-rise`, `.ln`, `data-scrub` hooks unchanged.

**`css/fx.css`** — preloader: paper sheet, mono label with a red dot, big **mono** count, 8px red progress bar on a rule track. Stats pill: ink pill, mono numbers, red heart when liked, red `+1` burst. Toast: ink pill with a red check disc.

**`css/nav.css`** — ink pill (cream pill in dark theme) always visible so it reads over cream, night and red bands; `.nav__brand` gets a red full stop; `.nav__pill` (the element `js/scroll.js` already positions) is now the **red active dot**, sliding with the active link; "Let’s talk" `.btn-pill` is inverted against the bar; theme toggle and menu button restyled for the bar; the mobile menu overlay uses display type and mono `01–06` indices.

**`js/theme.js`** — `theme-color` is now `#F2EFE9` / `#0B0B0B`, and it updates **every** `meta[name=theme-color]`, because W7 split the tag into two `media`-gated metas (a single `querySelector` would only have updated the light one).

`js/scroll.js`, `js/reveal.js`, `js/preloader.js` are untouched; their hooks (`.nav__pill`, `--px/--pw/--po`, `.is-active/.is-scrolled/.is-hidden/.is-away`, `data-count`, `.preloader__bar i`, `--p`) all still work.

If you need a surface token that is derived from paper/ink, read it from the band (`--color-card`, `--color-hover`, `--color-dot`, `--color-mark` are re-mapped).

- **W6**: `.footer` colours via tokens as the brief says; the stats pill (`.stats`) is `--color-ink` on `--color-paper` text, so inside a `.band--night` footer it renders cream. `.toast` is ink with a red check disc.
