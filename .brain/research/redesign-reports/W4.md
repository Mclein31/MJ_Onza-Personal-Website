# W4 Report — About & Journey

## Summary of Changes

### About (`#about`, `css/about.css`, `js/ui.js`)
- **Night band**: Converted `#about` to a full-bleed `.band--night` section (`<section class="section about band--night" id="about">` with inner `<div class="container">`), using cream (`--color-night-ink`) on black (`--color-night`) with subtle top/bottom hairlines so it stays distinct in dark theme.
- **Heading & highlight**: Added `02 / ABOUT` mono `.label` eyebrow. Kept `Student first, builder always, now learning <span class="hl">how data flows.</span>` with `.hl` styled as a signal-red (`--color-signal`) highlight box with ink (`--color-signal-ink`) text.
- **Profile facts**: Styled `.facts` as a single-column stack of mono label (`dt`) and value (`dd`) rows separated by `--color-rule` hairlines (`tabular-nums`, zero horizontal overflow on 375px+).
- **What I do accordion**: Reworked `.does` with a `.does__bar` header (`What I <em class="serif">do.</em>`, `03 DISCIPLINES` mono label, and `01 Build / 02 Model / 03 Automate` mono list) and three numbered rows (`01 Build`, `02 Model`, `03 Automate`). Open rows reveal a giant red `.numeral` (`01`–`03`) and turn the `+`/`−` icon chip signal-red.
- **Accordion JS (`js/ui.js`)**: Preserved one-row-open behaviour and `aria-expanded` updates in `does()`, and added `ArrowDown` / `ArrowUp` / `Home` / `End` keyboard focus navigation between `.does__btn` controls.
- **Signal anchors**: Added two `<i data-signal-anchor aria-hidden="true"></i>` markers inside `#about` (top-right of `.about__intro`, and between `.about__intro` and `.does`).

### Journey (`#journey`, `css/journey.css`, `js/journey.js`)
- **Cream band & intro**: Styled `#journey` with `.band--paper`, added `03 / JOURNEY` mono `.label` eyebrow and `Journey <em class="serif">so far.</em>` heading.
- **Giant outlined year numerals**: Added `data-yr-bg` attributes (`2022`, `2024`, `2026`, `NOW`, `NEXT`) on `.yr` slides rendered via `.yr::before` (`content: attr(data-yr-bg)`, transparent fill, signal-red `-webkit-text-stroke`) behind slide content, avoiding extra child elements in `measureFrame()`.
- **Typography & keywords**: Styled `.yr__year` in `--color-signal-text`, `.yr__place` in italic serif, `.yr__note h3` captions in italic serif (`--font-serif`), and `.yr__note .keyword` (including `Python` and `Postgres`) with signal-red underlines.
- **Mono progress label**: Updated `.years__foot` to `YEAR <b data-yr-i>01</b> / 07` in mono `.label` style with a signal-red active indicator dot.
- **Pinned & responsive behaviour**: Preserved `js/journey.js` pinning, transitions, measured phone/tablet stage (`--year-content`), short-landscape unpinning, and `prefers-reduced-motion` flow. Fixed `861px–960px` (`890×626` unfolded landscape) media `max-height` so `.yr__media` does not overlap `.yr__note`.
- **Signal anchors**: Placed `<i data-signal-anchor aria-hidden="true"></i>` markers before `[data-years]` (in `.journey__intro`) and after `[data-years]` (in `.journey__outro`), outside the pinned stage.
