# G2 — Navigation & Image Hygiene

## What Changed

### 1. Navigation bar (`css/nav.css`)
- Added `@media (max-width: 1024px)` to collapse `.nav__links` and `.nav__hire` into `.nav__menu-btn` (with `.nav__actions { margin-left: auto; }`) up to `1024px`, preventing desktop link overflow and overlap at `961px` (where `--gutter` widens from `24px` to `64px`).
- Added `@media (max-width: 1120px)` to slightly tighten `.nav__inner` (`gap: var(--space-sm); padding-left: 20px`), `.nav__links a` (`padding: 0 11px 0 20px`), and `.nav__pill::before` (`left: 9px`) so the `1025px–1120px` range (including `1032×1376`) keeps generous clearance around the link row and keeps the red active dot centered in each link's left padding.
- Kept `.nav { inset-block-start: var(--space-md); }` at `@media (max-width: 960px)`.

### 2. Image dimensions & lazy loading (`index.html`)
- **`#recognition` (5 award photos)** & **`#training` (8 training film frames)**: verified all 13 `<img>` elements already carried exact `width` and `height` attributes matching their source files' pixel dimensions (added in W5's pass), plus `loading="lazy" decoding="async"`. No edits needed.
- **`#contact`**:
  - Added `width="1600" height="900"` to the 3 `.contact__tile` project thumbnails (`advancare-1-1600.webp`, `medcore-1-1600.webp`, `servio-1-1600.webp`).
  - Added `loading="lazy"` to the below-the-fold contact icons/avatars:
    - LinkedIn `.pass__head` (`assets/icons/linkedin-brand.svg`, `24×24`)
    - LinkedIn `.pass__connection` (`assets/images/avatar.webp`, `36×36`)
    - WhatsApp `.pass__head` (`assets/icons/whatsapp.svg`, `24×24`)
    - Gmail `.pass__head` (`assets/icons/gmail.webp`, `24×24`)
  - Added `width="240" height="240" loading="lazy"` to `.compose__to` avatar (`assets/images/avatar.webp`, real size `240×240`).
- No other markup was modified.
