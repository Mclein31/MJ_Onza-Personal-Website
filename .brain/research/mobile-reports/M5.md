# M5 — Activity & Stack phone layout report

## Files changed
- `css/activity.css`
- `css/stack.css`
- `js/activity.js`
- `index.html` (targeted edit in `#stack` only: added `class="on-hover"` to the hover-hint paragraph)

`js/contributions.js` required no changes.

## What was removed / hidden
- **Activity (`<= 700px`)**:
  - Hid the 2nd (`Active days`) and 4th (`Best day`) stat cards via `.activity__stats .stat:nth-child(2), .activity__stats .stat:nth-child(4) { display: none; }`, leaving only `Total` (contributions) and `Longest streak`.
  - Removed the `174px` grey `.is-loading` placeholder box and `1100px` `min-width` on `.activity__cal.is-loading` and `.activity__cal.is-error` on phones.
  - Hid `.activity__legend` when `.activity` has `.is-error`.
- **Stack (`<= 700px` / touch)**:
  - Hid `#stack .section-head > p` (`"Point at a row to see what it joins across the stack."`) via `.on-hover` on touch devices and `@media (hover: none), (max-width: 700px)` in `css/stack.css`.
  - Hid row index numbers (`.row::before`) and the right-hand type column (`.row em`) at `<= 700px`.

## What was changed
- **`css/activity.css`**:
  - Replaced `@media (max-width: 40rem)` with `@media (max-width: 700px)` so all phone widths `<= 700px` get `--space-md` padding/margins on `.activity__scroll`, `.activity__foot`, and `.stat`.
  - Styled `.activity__cal.is-loading::before` as a compact one-line `"Loading GitHub activity…"` fallback (`min-width: 0; min-height: 0; background: transparent;`).
  - Styled `.activity__cal.is-error` and `.activity__error` as a compact one-line fallback with `0.8125rem` text.
- **`js/activity.js`**:
  - Added `.is-error` class and removed `role`/`aria-label` on `.activity__cal` when contribution loading fails; shortened fallback copy to `"Couldn’t reach GitHub. Open on GitHub ↗"`.
  - Increased `near` observer `rootMargin` from `600px 0px` to `1000px 0px` so contributions start loading earlier while scrolling.
- **`css/stack.css`**:
  - At `<= 700px`, collapsed `.schema` into a compact hairline-divided vertical list of 5 tables (transparent headers with `--color-signal-text` key icon and `PK`, plus `.table__rows` as wrapped plain Geist Mono `.row` items with `gap: 4px 14px`, zero pill borders, and `box-shadow` join highlights if tapped).
- Desktop (`>= 861px`) layout and styles are unchanged.
