# M1: motion and navigation core

Job M1, Redesign v5. Design-agnostic infrastructure in `scripts/core/`. Every module is a vanilla ES module that never throws and does nothing when its hooks are absent. Each has a header comment with the full hook, class, event and API list; the tables below are the summary.

## Files

| File | Role |
|---|---|
| `scripts/core/motion.js` | Shared GSAP, ScrollTrigger and Lenis setup |
| `scripts/core/intro.js` | Once-per-session intro gate, Skip, failsafe |
| `scripts/core/gl.js` | WebGL capability check, DPR cap, pausing render loop, fallback reporting |
| `scripts/core/nav.js` | Scroll-spy, header hide/show, phone menu, anchor routing |

Nothing else was touched. The throwaway harness (`prototypes/m1-harness/`) is deleted.

## Hooks (data attributes and CSS variables)

| Hook | Module | Meaning |
|---|---|---|
| `:root --header-h` | motion, nav | Fixed header height, any CSS length. `scrollTo` stops this far short of the target. nav.js sets it from `[data-header]` only if the CSS does not define it. |
| `[data-lenis-prevent]` | motion | Put on dialogs, the menu panel and the lightbox so they scroll natively under Lenis. |
| `[data-intro]` | intro | The loader overlay. Optional `data-intro-duration="1600"` auto-completes it. |
| `[data-intro-skip]` | intro | Skip control, any number. Escape also skips. |
| `[data-intro-hold]` | intro (CSS) | Elements the intro hides. Used by the CSS failsafe recipe. |
| `[data-header]` | nav | Header. Gets `is-hidden` and `is-scrolled`. |
| `[data-hero]` | nav | The header only hides after scrolling past its bottom edge. |
| `[data-nav]` | nav | Links with `href="#id"`. Get `aria-current="location"` and `is-current`. |
| `[data-menu-toggle]` | nav | Menu button(s). `aria-expanded` and `aria-controls` are kept in sync. |
| `[data-menu]` | nav | The menu panel. |
| `[data-menu-close]` | nav | Optional extra close buttons inside the menu. |
| `[data-menu-inert]` | nav | Optional. Made `inert` while the menu is open (main, footer). |
| `a[href="#id"]` | nav | Every in-page anchor is routed through `motion.scrollTo`. |

For `gl.js` the "hook" is the options: `canvas`, `root` (default: the canvas parent) and `target`.

## State classes

| Class | On | Set by | Meaning |
|---|---|---|---|
| `is-reduced-motion` | html | motion | Reduced motion is on (live). |
| `is-smooth-scroll` | html | motion | Lenis is running. Lenis also adds `lenis lenis-smooth lenis-stopped`. |
| `is-scroll-locked` | html | motion | At least one `lockScroll` key is held. |
| `is-intro` | html | intro | The intro is playing. Hide hero content under it. |
| `is-ready` | html | intro | The intro is over or never played. Removing `is-intro` and adding `is-ready` happen together. |
| `is-hidden` | header | nav | Scrolled down past the hero. |
| `is-scrolled` | header | nav | Not at the very top. |
| `is-current` | `[data-nav]` | nav | The active section. |
| `is-menu-open` | html | nav | The menu is open. |
| `is-open` | menu and toggles | nav | The menu is open. |
| `is-gl-ready` | gl root | gl | The first frame has rendered. Hide the poster under it. |
| `is-gl-fallback` | gl root | gl | WebGL is not running. `data-gl-fallback` holds the reason. Show the poster. |
| `is-gl-paused` | gl root | gl | The loop is asleep (offscreen or tab hidden). |

## Events

| Event | Target | Detail |
|---|---|---|
| `motion:change` | document | `{ reduced, smooth }`, after init and after every mode change |
| `motion:refresh` | document | none, after `ScrollTrigger.refresh()` |
| `intro:start` | document | none. The design's loader animation listens for this and calls `completeIntro()`. |
| `intro:done` | document | `{ reason, duration }`. Reason is `complete`, `skip`, `failsafe`, `repeat`, `reduced` or `noop`. Fired once. |
| `nav:change` | document | `{ id, previous, link }` (`id` is null above the first section) |
| `menu:change` | document | `{ open }` |
| `gl:ready`, `gl:pause`, `gl:resume`, `gl:recovered` | gl root, bubbles | `gl:pause` carries `{ reason: 'offscreen' \| 'hidden' }` |
| `gl:fallback` | gl root, bubbles | `{ reason }`: `no-webgl`, `save-data`, `low-memory`, `reduced-motion`, `small-touch`, `context-lost`, `render-error` |

## API

- **motion.js**
  - `initMotion({ lerp })`, `reducedMotion()`, `onMotionPreferenceChange(cb)` (returns an unsubscribe function).
  - `scrollTo(target, { offset, immediate, duration, onComplete })`, `refresh({ now })`.
  - `lockScroll(key)`, `unlockScroll(key)`, `headerHeight()`, `getLenis()`, `isSmoothScroll()`.
  - Re-exports `gsap`, `ScrollTrigger`, `SplitText`, `Flip`, `CustomEase`, `ScrollToPlugin`. Every module should import GSAP from here so there is one instance.
- **intro.js**
  - `initIntro({ maxMs, minPlayMs })`, `completeIntro()`, `skipIntro()`, `whenIntroDone()`, `introState()`.
- **gl.js**
  - `glSupport({ minMemory, allowSoftware, force })` returns `{ ok, reason }`. `canUseWebGL()` is its boolean form.
  - `clampDpr(max = 1.5, phoneMax = 1)`, `reportFallback(root, reason)`, `clearFallback(root)`.
  - `createGLLoop({ canvas, render, resize, root, target, margin, maxFps, onFallback, onRestore })` returns `{ start, stop, destroy, renderOnce, state }`.
- **nav.js**
  - `initNav({ initialHash })` returns `{ openMenu, closeMenu, toggleMenu, isMenuOpen, current, refresh, destroy }`.

## How to wire a page

1. In `<head>`, before the stylesheets, add the inline `is-intro` / `is-ready` script and the CSS failsafe from the `intro.js` header. Also link `vendor/lenis/lenis.css`.
2. Define `--header-h` in CSS and give targets `scroll-margin-top: var(--header-h)`.
3. Call `initMotion()`, `initIntro()` and `initNav()` from `main.js`.
4. Call `completeIntro()` when the loader timeline ends.
5. Under the phone breakpoint, hide a closed `[data-menu]` from focus with `visibility: hidden`.

## Decisions worth knowing

- **intro.js has no GSAP import.** If a vendor file fails, the page can never stay hidden.
- **Failsafe timing.** The JS failsafe fires at 2.5s from navigation start (`performance.now()`), so a late module cannot extend the wait. It never fires earlier than 400ms after init. The CSS fallback fires at 2.6s, so JS wins when it is alive.
- **CSS failsafe keyframes use `1%, 100%` stops, not `to`.** My first version used `to` and failed in real Chrome. A 1ms animation can stall at progress 0.99999999999989, so `visibility` never flipped (found by the harness; opacity went to 0 but the overlay stayed `visibility: visible`). The documented recipe has the fix.
- **`glSupport` runs a real context probe.** It uses `failIfMajorPerformanceCaveat` by default, so software rendering counts as "no WebGL". Pass `allowSoftware: true` for CI or headless runs. Cheaper checks run first: reduced motion, saveData or 2g, `deviceMemory < 4`, and a coarse pointer with a short side under 700px. The probe context is released with `WEBGL_lose_context`.
- **Scroll lock.** Lenis uses `lenis.stop()`; native scroll uses inline `overflow: hidden` on `<html>`. Neither depends on the design CSS. `scrollTo` returns false while a lock is held, so nav.js closes the menu before it scrolls.
- **Lenis settings.** `lerp 0.1`, `syncTouch: false`, `allowNestedScroll: true`, `anchors: false` (nav.js owns anchors). Lenis is created or destroyed live when reduced motion or the pointer type changes.
- **Late media.** `refresh()` is debounced. It fires after fonts, window load, and every late `<img>` load or `<video>` `loadedmetadata`, caught with capture listeners on `document`.
- **Header hide/show.** It uses a direction-change reference point with an 8px dead zone, so slow Lenis frames still register. The header also shows while focus is inside it.
- **Anchor clicks.** After an anchor scroll, the URL hash is updated with `pushState` and focus moves to the target (`tabindex=-1` is added if needed). A page opened with a hash is scrolled under the header after load.
- **Known behaviour:** an anchor click that scrolls down hides the header, which is standard. The visitor scrolls up to reach the menu toggle again.

## Verification

Throwaway harness `prototypes/m1-harness/index.html` plus `node tests/serve.mjs 4319`. Real Chrome at 1440x900 for desktop, WebKit iPhone 14 and Chrome Pixel 7 for phones. The harness had a header, menu, hero with a WebGL canvas, three sections, a scrubbed ScrollTrigger and an intro overlay. Harness and test script are deleted (the script was in the session scratchpad). **52/52 checks passed; no page errors.**

- **Lenis**
  - Runs on desktop (`is-smooth-scroll`, `lenis.scroll == window.scrollY`) and is absent on the iPhone 14 and Pixel 7 touch emulations.
  - Starts or stops live when reduced motion is toggled with `emulateMedia`.
- **ScrollTrigger sync:** after a Lenis wheel scroll, scrubbed progress equals the progress expected from `scrollY` (0.3037 vs 0.3037), and the trigger start equals the section's document offset.
- **Intro**
  - Plays once: first load fires `intro:done` with reason `complete` and sets `sessionStorage v5-intro`. Reload fires `repeat` at about 31ms with no `is-intro`.
  - Skip button and Escape give `skip`.
  - Reduced motion gives `reduced` with no `intro:start`.
  - Blocked `sessionStorage` still completes without throwing.
  - JS failsafe: with a loader that never completes, `failsafe` fired at 2459ms.
  - CSS failsafe: with `intro.js` blocked, content was hidden at 0.3s, and the overlay had `visibility: hidden` with the hero at opacity 1 by about 3.1s.
- **Scroll-spy**
  - Clicking About gives `aria-current="location"` on both nav copies, the hash `#about`, focus on the section, and the section top exactly at `--header-h` (64px).
  - The last short section (Contact) is current at the bottom of the page.
  - It clears in the hero.
- **Header:** hides on scroll down past the hero, shows on scroll up, and is visible at the top.
- **Phone menu**
  - iPhone 14 (WebKit): opens with `aria-expanded`, `is-menu-open` and scroll lock, focus on the first link, and `[data-menu-inert]` applied. Escape closes and returns focus to the toggle. A link tap closes the menu and scrolls under the header. It auto-closes when resized to desktop. Tab wraps at both ends, and focus forced onto page content is pulled back.
  - Pixel 7 (Chrome): full cycle `About > Contact > Close > Menu > Work > About > Contact`, Shift+Tab backwards and wrap, Escape closes.
- **GL**
  - At the top: running, with `is-gl-ready`.
  - Scrolled offscreen: `running=false`, frame count frozen, `is-gl-paused` and `gl:pause` (reason `offscreen`).
  - Back in view: frames resume.
  - Tab hidden: loop stops (`gl:pause` reason `hidden`), and resumes when visible.
  - Context lost then restored: `context-lost` fallback with `is-gl-fallback`, then `recovered` and running again.
  - Reduced motion: `glSupport` returns `reduced-motion` and the poster stays.
  - iPhone 14: `small-touch` fallback.
- **Hook-free page:** with all four modules imported and every function called on a page without hooks, there were no errors and no storage write (`intro` resolved `noop`).

## Known gaps

- Safari's default "Tab skips links" setting means a link-only menu is not fully Tab-reachable in real Safari. That is the visitor's browser setting; the trap only manages the edges. The WebKit test checked the wrap edges, not link-to-link Tab.
- `intro.js` does not draw anything: the design's loader must call `completeIntro()` or set `data-intro-duration`.
- No pinned-section integration was tested (no `pin: true` in the harness). `nav.js` and `motion.js` rebuild on `motion:refresh`, so pin spacers should be fine, but a real pinned Work section needs a pass.
- The GL support check ran in headless Chrome with a real GPU. Weak-device heuristics (`deviceMemory`, `saveData`) are logic only; the browser APIs were not mocked.
