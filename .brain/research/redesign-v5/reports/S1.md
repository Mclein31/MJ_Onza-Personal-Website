# S1: v5 behaviour spec (written by the orchestrator after verification)

Spec: `tests/v5-behaviour.spec.mjs` (agy workers 20 and 21). Projects `v5b-desktop` (Chrome 1440x900),
`v5b-iphone14` (WebKit), `v5b-duo-folded` (WebKit 466x678, touch, DPR 3). Script: `npm run test:v5`.
Page path from `V5_PATH` (default `/prototypes/skeleton/`; switch to `/` once the build moves to the root).
Selectors are data hooks, ids and ARIA only. All external services are mocked through `tests/fixtures.mjs`.

## Result
Orchestrator ran `npx playwright test v5-behaviour.spec.mjs --project="v5b-*" --retries=0` three times in a row
on 2026-11-23: **48 passed, 3 skipped, 0 failed** each time.

## What was wrong
The first version failed the desktop nav/scroll-spy test reproducibly (expected `#work`, got `#about`): the test
scrolled with a plain `window.scrollTo` while Lenis smooth scrolling was active on desktop. Worker 21 changed the
test to scroll like a user and wait for the scroll to settle. The page (`scripts/core/nav.js`) was not changed.

## Skips (intentional)
- `nav jump and scroll-spy (desktop)`: `test.skip(hasTouch)` on `v5b-iphone14` and `v5b-duo-folded` (2 skips).
- `phone menu focus trap and Escape (touch)`: `test.skip(!hasTouch)` on `v5b-desktop` (1 skip).
