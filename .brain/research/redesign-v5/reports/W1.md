# Report W1: foundation, loader, nav and hero ("Instrument")

## Built
**Shared components (`styles/base.css`, brief section 3, exact names)**
- Buttons: `.btn` (2px, Geist 500, gap 10px, `--btn-h` 44px, 40px at >=1024px with a fine pointer, cobalt focus ring
  2px/offset 2px, press `scale(0.98)` 100ms, hover 160ms ease-out). `.btn--primary` + `.btn__mark` (orange square),
  `.btn--secondary` (1px inset outline), `.btn--ghost` (hairline under the label, ink line grows on hover, `.btn__arrow`
  slides → or ↗ for `target=_blank` / `.btn__arrow--ext`), `.btn--icon` (44/40 square, `--rule` border, ink on hover),
  `.btn--sm` (36px, fine pointer only), disabled (`:disabled` / `aria-disabled`: 40%, no pointer events), `.seg`
  (single toggle button with `[data-seg]` halves following `html[data-theme]`, or a group of `button.seg__opt[aria-pressed]`).
  Colours come from `--btn-ink` / `--btn-ground` on `.btn`, so a section on an ink field can flip them in one place.
- `.label`, `.rule` (+ `.rule--ink`), `.section-head` (label cols 1-3 with an orange index square, H2 cols 4-12,
  optional `.section-head__lede`; stacked under 720px), `.container` (12 cols, 4 on phones, margin `--m`, gutter `--g`),
  `.plate` (white/raised mount, inset hairline, four corner ticks drawn with gradients outside the box; it does not clip).
- Theme switch: circular View Transition reveal from the click point (`::view-transition-new(root)` +
  `--theme-x/y/r` from `core/theme.js`).
- Tokens (`styles/tokens.css`): `--theme-color-light/dark` (#E9EAEC / #0F1012, read by theme.js), `--scrim`,
  `--btn-h`, `--section-gap`, `color-scheme: only light` under `[data-theme=light]`.

**Reveal system (`scripts/design/reveal.js` + base.css)**: `data-reveal="rise|draw|fade"`, `data-reveal-stagger`
(60ms, children inherit the parent's value or `rise`), `data-tick` (count-up keeping prefix/suffix/commas/decimals/
leading zeros, `data-tick-from`, stops if another module rewrites the text), `data-scan` (media wipes top-down with a
2px orange line via WAAPI), `data-reveal-delay`. `html.has-reveal` is set in the `<head>` script (not under reduced
motion) so nothing flashes; reveal.js adds `reveal-live`; a CSS failsafe shows everything at 4s if it never runs.
In-view elements wait for `intro:done`. Exports `observe(root)` and `reveal(el)` for late markup.

**Loader** (`styles/loader.css` + markup): 000-100 counter, orange scan bar drawing the 12 column hairlines, Type/Field/
Grid status, "Skip intro" ghost button, counter lifts out on exit. Driven by a small inline script from first paint
(budget from navigation start, ~1.6-1.9s), finished by an inline module calling `completeIntro()`;
`data-intro-duration="2400"` and intro.js's 2.5s failsafe as backstops. Once per session, none under reduced motion.

**Nav** (`styles/nav.css` + markup): name, 8 section links with the orange square on `[aria-current]`, mono readout
(section name + 000-100%, shown >=1440px and in the 721-1179px bar), Light/Dark `.seg`, "Let's talk" primary small.
Under 1180px the links move to a full-height panel (clip-path drop, links rise 40ms apart, 01-08 mono indexes;
two columns on short landscape such as 890x626). Theme toggle and "Let's talk" stay in the bar at every width
(sun/moon icons under 720px, brand shortens to "McLein" under 440px). Bar drops in and its rule draws on entry.

**Hero** (`styles/hero.css`, `scripts/design/hero.js` + markup): spec strip (Program, University, Class of with a
2024→2028 tick, Looking for), the Extract/Transform/Load WebGL field ported from the prototype (raw WebGL, 4,096 points
desktop / 2,048 touch, DPR <=1.75/1.5) on `core/gl.js` (`glSupport`, `createGLLoop` pause offscreen/hidden tab,
context-loss restore, `reportFallback`), static SVG poster fallback (`assets/images/hero-field-{grey,orange}.svg`,
copied from the prototype, which still uses its own copy), name rising line by line, intro line, "See the work"
primary + "Send a message" secondary. Desktop with a fine pointer holds the hero half a screen while points settle
onto the hairlines; touch never pins. The 24 tool icons (content inventory) are kept as a quiet "Toolchain 24" row
under the hero (grey, colour on hover, dark marks inverted in dark mode). Entrance animations are CSS keyed on
`html.is-ready`, so a dead script can never leave the hero blank. 890x626 short-landscape layout kept from the
prototype; at 961-1199px the aside moves under the name (fixed a 1024x768 overlap).

**Head**: theme-color metas match the tokens; `has-reveal` gate; modulepreload for intro.js, reveal.js, hero.js, gl.js.
