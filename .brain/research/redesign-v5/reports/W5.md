# Report W5: GitHub Activity (`#activity`) & Stack (`#stack`)

Built `#activity` and `#stack` in the Instrument redesign v5 style (`styles/activity.css`, `styles/stack.css`, `scripts/design/activity.js`, `scripts/design/stack.js`, and the `#activity` / `#stack` markup in `index.html`).

## What was built

### `#activity` (GitHub Activity)
- **Layout & shared structure**: Uses `.section-head.container`, `.label`, `.rule` (`data-reveal="draw"`), `.btn.btn--ghost`, `.btn__arrow`, and `data-tick` without redefining shared classes from `styles/base.css`. Added `data-reveal-stagger` on `.section-head` so header elements reveal reliably at all widths.
- **Instrument readout panel**:
  - Square contribution cells (`aspect-ratio: 1 / 1` inside flex-column `[data-week]` tracks) with `2px` gaps (`--act-gap: 2px`) and `var(--r)` (`2px`) radius.
  - Cool-grey ramp ending in international orange (`--orange`) for level 4 across both light (`#E2E4E8` → `#C2C6CE` → `#8D939E` → `#3C4047` → `#FF4F00`) and dark (`#202328` → `#363B42` → `#626873` → `#AEB4BE` → `#FF5A1A`) themes, mirrored by the 5-swatch legend (`data-level="0..4"`).
  - Horizontal scroll contained inside `.activity__scroll` (`overflow-x: auto`, `overflow-y` left `auto` so `p[data-activity-summary]` is never clipped) with a sticky weekday gutter (`.activity__weekdays` `Mon`/`Wed`/`Fri`) and month labels above columns.
  - Calm left-to-right scanning shimmer (`@keyframes act-scan` using `transform`) over a subtle 14px dot lattice while `[data-state="loading"]`, disabled (`display: none`) under `prefers-reduced-motion: reduce`.
  - Error state (`[data-state="error"]`) with orange status square and `.btn.btn--ghost` actions (`Open on GitHub ↗` and `Retry →`).
  - Four-cell Geist Mono instrument readout strip (`Total`, `Active days`, `Longest streak`, `Best day`) with tabular numerals, active orange top hairline + indicator LED when `[data-hl]` highlights are toggled, and floating tooltip (`[data-act-tip]`).
- **Motion (`scripts/design/activity.js`)**: Listens to `activity:ready` and `activity:state`. Animates week columns left-to-right via WAAPI (`520ms` stagger + `240ms` duration = `760ms` < 900ms total) and counts up `[data-act][data-tick]` (`680ms` cubic ease-out). Sets `data-tick-from` once loaded (cleared on non-ready states) so `reveal.js` does not double-count stats on subsequent scrolling. Disables motion immediately under `prefers-reduced-motion: reduce`.

### `#stack` (Schema Tables & Join Highlighter)
- **Layout & shared structure**: Uses `.section-head.container`, `.label`, `.rule`, `.section-head__lede`, `data-reveal-stagger`, and semantic `<table>` elements preserving all `data-schema`, `data-join`, `id`, `aria-labelledby`, `<thead>`, `PK`, skill names, and column types verbatim.
- **Data-engineering schema styling**: Mono table names (`.stack__name`), `1px` `--ink` header border, hairline row dividers, PK numbers aligned vertically beneath the table header LED and `PK` label, right-aligned mono types, and `>= 44px` touch row heights (`padding-block: 12px`).
- **Responsive grid**: Stacks all 5 tables in a single column on phones, `768x1024`, and all three iPhone Duo postures (`466x678`, `626x890`, `890x626`), stepping to 2 columns at `960px` and the 2-over-3 6-track schema layout at `>= 1120px`.
- **Join highlighter (`scripts/design/stack.js`)**: Hovering (`pointerenter` for mouse), focusing (`focus`), tapping/clicking (locks/unlocks), or pressing `Enter`/`Space` on any `<tr data-join>` highlights matching rows across all tables with orange markers (`tbody th::before`), lights participating table headers (`.has-join`), dims non-matching rows, and updates the live status readout (`[data-schema-status]`). Supports `Escape` to clear and `ArrowUp`/`ArrowDown` navigation within a table.
